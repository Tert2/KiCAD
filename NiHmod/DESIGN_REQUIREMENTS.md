# NiHmod 設計指示まとめ

このプロジェクトでユーザーが出した回路設計・基板設計の指示を、トピックごとにまとめたものです。
質問への回答で決まった事項も含みます。

---

## 1. 回路の目的と構成
- NiMH 電池を充放電する回路を作る。
- 充電IC は **BQ25172** を使う。
- **パススルー回路**を付け、充電中も負荷を使えるようにする。
- **CUHS20S30** を電源経路のダイオード(パススルーの VBUS → VOUT)に使う。
- **NCP15XH103** をサーミスタ(電池温度の検出)に使う。

## 2. 動作条件(質問への回答で決定)
| 項目 | 指定 |
|---|---|
| セル数 | NiMH **3セル直列**(3.6V) |
| 入力電源 | **USB 5V** |
| 電池容量 / 充電電流 | 約 **2000mAh / 500mA** |
| 電池ボックス | 秋月「電池ボックス 単3×3本 リード線・フタ・スイッチ付」(SBH-331AS) |
| スイッチの位置 | **電池側**(電池ボックスの元の配線のまま) |

## 3. 部品の選び方
- **抵抗**:1005 サイズ。
- **コンデンサ**:1608 以下・1005 以上で、容量と耐圧を考慮して選ぶ。
- **BQ25172 と抵抗以外**:秋月電子で手に入る部品から選び、型番などの詳細まで詰める。
- **LED**:1005 サイズに変更する(Yamaha ライブラリに LED は D1005 しかないため)。
- **サーミスタ**:基板には載せない。電源と同じ SMD パッド(TS / GND の専用2パッド)にリード線でつなぎ、電池の近くに置く。

## 4. 基板の外形と実装
- 電池ボックスの中に入れる。当初の目安は 15mm × 25mm 程度。
- SBH-331AS のスイッチ部の隙間に入るか調べる。調べた結果、**12 × 20mm の基板を縦に差し込む**ことにした。
- パッドは基板の**両端に分ける**。片側が電池側(B+ / B-、サーミスタ TH / TH)、反対側が USB と負荷側(GND / IN / OUT)。
- **充電表示LED は載せる**(箱のふたに穴を開けて見る前提)。

## 5. 電源・接続用 SMD パッド
- **GND / Vin / Vout** を、2.54mm ピッチ・幅 2mm の SMD パッドで作る。
- 電池側の **BATT+ / BATT-** も、2.54mm ピッチ・幅 2mm の SMD パッドで作る。
- パッドには、どの端子か分かるように**端子名をシルクで書く**。

## 6. 設計ルール
| 項目 | 指定 |
|---|---|
| ビア外径 | **0.5mm** |
| クリアランス | 配線もベタ塗りも**すべて 0.2mm** |
| 配置グリッド | **0.1mm** |

## 7. 配線
- 配線は **X 軸と平行・Y 軸と平行・45° の線分だけ**を使う。直角には曲げず、斜め 45° でつなぐ。
- **パッドオンビアを使ってよい**。
- **裏面**:全面を GND ベタにする。GND は貫通ビアで落とし、ベタでつながるようにする(GND の配線はしない)。GND ベタには、配線をなるべく通さない。
- **表面**:Vcc(VBUS / VOUT)と VBAT のベタで区切って配線する。
- **VBUS は細くしない**。ベタ塗りでつないでよい。
- 1005 / 1608 のパッドは間隔が広いので、R などの部品のパッドの間に配線を通してよい。

## 8. 部品配置
- **LED まわり**:STAT ピンの近くに部品を置いて、電流ループを小さくする。
- **機能ごとにまとめる**:パスコン(バイパスコンデンサ)や、プルダウン / プルアップ抵抗は、その動作を必要とするピンの間近に置く。
- **D1**:外形枠(マージン)を取りすぎているので縮小する。

## 9. シルク
| 対象 | 文字サイズ | 太さ |
|---|---|---|
| 電源パッドなどの端子名 | 1mm × 1mm | デフォルト |
| 部品の番号など | 0.5mm × 0.5mm | デフォルト |

## 10. フットプリント
- 1005 / 1608 の部品には、ユーザーが作成した **Yamaha ライブラリ**のフットプリントを使う。
- 名前は「部品の頭文字 + サイズ」になっている(R1005、C1608、D1005 など)。
- 名前が当てはまらないものは、対応する 3D モデルの設定を見て判断する(例:1005 のコンデンサは `1005`)。

---

## ユーザー側で決める事項
- **抵抗値はユーザーが検討して付ける。**
  - 特に R2(VBUS のプルダウン、回路図上は 100k)。
  - 参考:D1(ショットキー)は逆方向の漏れ電流が大きいので、10k〜4.7k 程度が目安。
